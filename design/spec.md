# DeepSeek Meter · 设计规范 v1

> 交付物：`design/mockup.html`（交互设计稿）+ 本文件（实现规格）
> 目标平台：macOS 13+（Apple Silicon / Intel），原生 Swift，无第三方依赖

---

## 1. 目标

一个常驻桌面的 66×35 挂件，随时能看到 DeepSeek 账户余额；鼠标悬停展开今天 / 近 7 天 / 近 30 天的消耗金额（人民币）。

**做**：挂件、悬停卡片、三周期金额、7 日迷你柱、刷新与错误状态、设置、首次启动、本地历史采样。
**不做（v1）**：官方精确用量抓取、图表详情窗口、菜单栏余额数字、通知、多账号、iCloud 同步。

---

## 2. 视觉规格

### 2.1 挂件（66 × 35，扁平矩形）

圆形在 35pt 下只有 33pt 内宽，放 `¥94.1` 几乎没有余量；改成横向矩形后同样的高度能多出 33pt 宽度。

| 项 | 值 |
| --- | --- |
| 尺寸 | `66 × 35`（高可在设置里选 31 / 35 / 39；宽 = 高 × 1.886，圆角 = 高 ÷ 3.5） |
| 底板 | 实色 `#111419`，圆角矩形（35pt 时圆角 10）；**无渐变、无高光、无内阴影、无投影、无描边** |
| 数字 | `14 × 高/35`（35pt 时 14pt）`/ w600`，`tabular-nums`，字距 −0.02em，纯白 |
| 货币符号 | `¥` 与数字同排，`9.8 × 高/35`、opacity .85、与数字基线对齐 |
| 进度条 | 底部内嵌：高 2pt、左右各内缩 8pt、离底 4.5pt；轨道 `#2B313C`，进度 `#4D6BFE`，胶囊端 |
| 低余额 | 进度条转 `#E5484D`；底板与白字不动 |
| 离线 | 底板 `#3A3F49`、条 `#8A919D`、字 `#E6E9EE` |
| 未配置 | 底色同正常，隐藏进度条，字 `···`（字距 .14em，`#9AA1AD`） |
| 静止 / 悬停 | 静止 `opacity .5`，悬停或卡片展开 `1`，200ms；悬停另加 `scale(1.03)` |

**数字格式**：`< 1000` → 一位小数（`¥82.4`）；`≥ 1000` → `¥1.2k`；
5 位数字降到 12.5pt、6 位以上降到 11pt（同为 35pt 基准，按比例缩放）。

**进度条的语义**：`今日花费 / 日预算`（默认 ¥10，可关）。关掉后只留文字，不再占底部空间。

> **为什么从圆改成矩形**：圆的可用内宽只有 `直径 − 2×环宽`，35pt 时只剩 33pt，`¥` + 四位数字必然贴边；
> 矩形把同样的高度变成 66pt 宽，文字有 13pt 的左右余量，同时底部还能放一条进度条而不挤压数字。

### 2.2 悬停卡片（268 宽）

| 项 | 值 |
| --- | --- |
| 宽 / 圆角 / 内距 | `268` / `16` / `14` |
| 背景 | `rgba(14,18,30,.86)` + 22px 高斯模糊 + 饱和 150% |
| 描边 | `1px rgba(255,255,255,.10)` + 顶部内高光 |
| 高度 | 悬停 `258`；固定态 `305`（多一行操作按钮） |
| 间距 | 与挂件 `10`；屏幕安全边距 `8` |

结构（上→下）：

1. `余额 · CNY` ／ 右侧同步状态（`● 刚刚更新` / `同步中…` / `离线 · 12 分钟前`）
2. 余额大字 `23pt / w680`（¥ 前缀 13pt） ／ 右侧 `今日 −¥1.23`
3. 分隔线
4. 三列：`今天` `近 7 天` `近 30 天` — 标签 `10.5pt`，数值 `15pt / w650`，第三行对比（`↑12%` / `↓4%` / `≈ 日均 1.14`）
5. 7 日迷你柱（26px 高，今日高亮渐变 `#9CB0FF→#5C79FF`，首尾日期标签）
6. 分隔线
7. `充值 ¥100.00 · 赠金 ¥0.00` ／ 右侧 `已记录 12 天`
8. （固定态）操作行：`设置` `打开平台` `刷新`

### 2.3 文字与色板

| 用途 | 值 |
| --- | --- |
| 主文字 | `#F4F7FF` |
| 次要文字 | `#98A2BD` |
| 弱文字 | `#6A748C` |
| 品牌 / 环 | `#4D6BFE` / `#8AA0FF` |
| 花费（涨） | `#F5A3A3`（暗底柔和红，不用纯红） |
| 节省（降） | `#7FD9B8` |

字号只出现在 4 档：`23 / 15 / 12 / 10.5`，全部数字用 `tabular-nums`。
主界面只做深色（悬浮在任意壁纸上都稳定）；浅色模式留 v2。

## 3. 交互规格

### 3.1 挂件的交互

- **悬停 120ms** 后展开卡片（防抖，避免划过误触）。
- **点击**固定卡片；再次点击、点空白处、`Esc` 收起。
- **拖动**移动；松手后吸附到最近的屏幕边缘（8px 边距），位置持久化。
- **双击**打开设置；**右键**弹出菜单（刷新 / 固定 / 设置 / 打开平台 / 隐藏 / 退出）。
- 快捷键：`⌥⌘H` 显隐，`⌘R` 刷新，`⌘P` 固定卡片。
- 鼠标离开挂件 + 卡片区域 300ms 后收起（10px 间距属"桥接区"，不打断）。

### 3.2 卡片朝向

挂件中心在屏幕左半 → 卡片在右；右半 → 卡片在左；靠近顶部 → 向下展开。
垂直方向以挂件中心对齐后 clamp 到屏幕可见区域 8px 内边距。距中线 < 8px 时保持上一次朝向，避免抖动。
多屏：始终使用挂件所在屏幕的 `visibleFrame`；显示器变更时重新计算。

### 3.3 状态矩阵

| 状态 | 挂件 | 卡片 |
| --- | --- | --- |
| 正常 | 余额 + 环 | 正常数据 |
| 低余额 `< ¥5` | 红环 + 红点 4s 呼吸 | 正常，顶部加一行提示 |
| 未配置 Key | `···` + 琥珀点 | 引导填写 Key |
| 网络失败 | 降透明，保留旧值 + 琥珀点 | 缓存数据 + `离线 · 12 分钟前` |
| 401 / Key 失效 | 保留旧值 + 红点 | 内联红色错误 + `重新填写 Key` |
| 首次加载 | `···` | 骨架屏（不阻塞 hover） |

原则：**任何时候都不显示误导性的 0**；失败时展示"上次成功的值 + 它有多旧"。

## 4. 数据口径

### 4.1 接口

```
GET https://api.deepseek.com/user/balance
Authorization: Bearer <API Key>
→ { is_available, balance_infos: [{ currency: "CNY", total_balance, granted_balance, topped_up_balance }] }
```

- 这是**唯一**可用的余额接口，官方没有"按天用量"API。
- 多个 `balance_infos` 时优先 CNY；只有 USD 时挂件内显示 `$`。
- Key 存 Keychain（`kSecClassGenericPassword`），不进设置文件、不写日志。

### 4.2 用量推算（余额差值法）

每次成功轮询写一行采样 `(ts, total, granted, topped)`：

- `Δ = prev.total − cur.total`
- `Δ > 0` → 记为消耗，归属 `cur.ts` 的本地自然日
- `Δ < 0` → 余额上升，视为充值 / 退款，不计入花费（用 `topped` 变化识别充值）
- 例外：赠金过期同样让余额下降，仅凭余额分不出来，按消耗计（罕见、金额小）
- 今日 / 7 天 / 30 天 = 对日桶求和（含今天）

**误差**：两次采样之间的消耗整体归到结束时刻那天，跨零点最多错一次采样量（≤5 分钟）；充值不会污染花费。首次安装只能从当天开始累积，所以不足 7/30 天时数字前加 `≈`，卡片底部显示 `已记录 N 天`。

**升级路径（v2 可选）**：抓 `platform.deepseek.com` 的用量接口（需用户粘贴 Cookie）可拿官方精确值，但登录态会过期、接口未公开，因此不做进 v1 主路径。

### 4.3 刷新节奏

- 默认 5 分钟（可选 1 / 5 / 15 / 30）。
- 触发点：定时器、系统唤醒、网络恢复、卡片展开且数据 > 60s、手动 `⌘R` / 按钮。
- 失败退避：10s → 30s → 60s → 300s，成功后重置。
- 请求超时 10s；错误分类：网络 / 401 / 429 / 5xx / 解析失败。

## 5. 技术方案

| 层 | 选择 | 说明 |
| --- | --- | --- |
| 窗口 | `NSPanel`（挂件窗口 74×43 + 卡片窗口独立） | `.nonactivatingPanel`、`level = .statusBar`、`canJoinAllSpaces + fullScreenAuxiliary`、透明无边框、不抢焦点 |
| 内容 | SwiftUI + `NSVisualEffectView(.hudWindow)` | 玻璃背景，数字 `.monospacedDigit()` |
| 状态 | `@MainActor` 单例 `AppModel` + `ObservableObject` | 采样、聚合、错误态 |
| 存储 | SQLite3（系统库）+ Keychain + UserDefaults | 采样表保留 90 天，日聚合永久 |
| 网络 | `URLSession` async/await | 自带重试与退避 |
| 登录启动 | `SMAppService.mainApp` | ad-hoc 签名失败时回退 `~/Library/LaunchAgents` plist |
| 构建 | SwiftPM + `scripts/build_app.sh` | 本机无 Xcode：`swift build --arch arm64 --arch x86_64` → 组装 `.app` → ad-hoc `codesign` |
| 权限 | 无需特殊权限 | 非沙盒、`LSUIElement=true`（无 Dock 图标） |

**双窗口的理由**：挂件窗口尺寸固定，卡片单独一个窗口出现/消失，避免 hover 时改变挂件窗口尺寸造成的 tracking 抖动与点击穿透问题。

**目录结构（实现阶段）**

```
Package.swift
Sources/DeepSeekMeter/
  main.swift            # NSApplication 启动
  AppModel.swift        # 状态、轮询、错误
  BalanceAPI.swift      # /user/balance
  Store.swift           # SQLite 采样与聚合
  WidgetPanel.swift     # 挂件窗口
  CardPanel.swift       # 卡片窗口 + 定位/翻转
  Views/                # SwiftUI：BallView, CardView, SettingsView, OnboardingView
  Prefs.swift  Keychain.swift  LoginItem.swift
Resources/Info.plist  AppIcon.icns
scripts/build_app.sh    # 打包 + 签名 + 安装到 /Applications
```
